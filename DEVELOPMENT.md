# Development Setup & Developer Experience Guide

## 1. Local Environment Setup
Follow the step-by-step instructions in [README.md](file:///c:/Users/LENOVO/soliqli/soliqli-1/README.md) to initialize the local development environment using Node.js v20, pnpm, Python 3.13, and Docker Compose.

## 2. Useful Commands
```bash
# Start all apps in watch mode
pnpm dev

# Run all test suites
pnpm test

# Format code across monorepo
pnpm format

# Start local Docker infrastructure (Postgres, Redis, MinIO)
pnpm docker:up
```
